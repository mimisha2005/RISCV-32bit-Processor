# 32-bit RISC-V Processor Design

## Overview
Designed and implemented a 32-bit RISC-V processor using Verilog HDL and Xilinx Vivado.

## Tools & Technologies
- Verilog HDL
- Xilinx Vivado
- Digital Logic Design
- RTL Design and Simulation

## Project Structure
- `riscv_top.v` – Top-level processor module
- `alu.v` – Arithmetic Logic Unit
- `control_unit.v` – Control signal generation
- `register_file.v` – Register storage and access
- `riscv_tb.v` – Testbench for simulation

## Key Features
- 32-bit processor architecture
- Modular RTL design
- ALU operations and control logic
- Functional simulation using a Verilog testbench

## How to Run
1. Clone this repository.
2. Open the `.xpr` project file in Xilinx Vivado.
3. Run behavioral simulation.
4. Review the RTL design and simulation waveforms.

## Tools
Xilinx Vivado | Verilog HDL
